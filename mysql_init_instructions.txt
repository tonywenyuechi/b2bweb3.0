# ShopXO系统初始化指南

## 问题分析
您遇到的HTTP 500错误是因为ShopXO核心系统的表（如`sxo_config`）不存在。这是因为您只创建了B2B电池交易平台的表，但没有创建ShopXO核心系统的表。

## 解决方案
您需要在MySQL命令行中执行完整的初始化脚本，创建所有必要的表。

## 执行步骤

1. **打开MySQL命令行客户端**
   您已经成功登录到MySQL命令行客户端，显示如下：
   ```
   mysql> 
   ```

2. **执行初始化脚本**
   在MySQL命令行中运行以下命令：
   ```sql
   SOURCE g:/b2bweb3.0d/init_shopxo_full.sql;
   ```

3. **等待执行完成**
   脚本执行过程中会显示大量输出，包括表的创建信息和索引信息。
   当您看到以下输出时，表示初始化完成：
   ```
   +---------------------------------------------------------------+
   | ShopXO系统和B2B电池交易平台初始化完成！                        |
   +---------------------------------------------------------------+
   ```

4. **测试ShopXO访问**
   脚本执行完成后，刷新浏览器中的ShopXO页面（http://localhost:8000），应该能正常显示，不再出现HTTP 500错误。

## 常见问题

1. **如果执行过程中提示"ERROR 1044 (42000): Access denied for user 'root'@'localhost' to database 'shopxo'"**
   - 请确保您有足够的权限访问shopxo数据库
   - 或者使用`CREATE DATABASE shopxo;`命令创建数据库

2. **如果执行过程中提示"ERROR 1050 (42S01): Table 'xxx' already exists"**
   - 这是正常的，脚本使用了`CREATE TABLE IF NOT EXISTS`语句，不会覆盖现有表

3. **如果执行完成后仍然出现500错误**
   - 请检查PHP错误日志，看是否有其他错误
   - 确保MySQL服务正在运行
   - 确保数据库连接配置正确

## 后续步骤

初始化完成后，您可以：
1. 访问ShopXO安装页面，完成安装向导
2. 登录ShopXO后台，配置B2B电池交易平台
3. 开始使用和测试B2B电池交易平台的各项功能

祝您使用愉快！
